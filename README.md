## Descripción
Este repositorio contiene la implementación en Java del algoritmo de Regresión Lineal Simple utilizando el método de Mínimos Cuadrados. El programa calcula la ecuación de la recta (pendiente y ordenada al origen), así como el coeficiente de correlación de Pearson ($r$) y el coeficiente de determinación ($r^2$), validando un conjunto de datos de prueba para realizar predicciones.
